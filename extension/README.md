# Extensión de Block (Chrome / Edge)

Bloquea las webs de tu lista mientras hay una sesión de Block activa en este PC.
Lee el estado de la app de Windows en `http://127.0.0.1:47613/state`. Si Block
no está abierto, no bloquea nada.

## Instalar (modo desarrollador)

1. Abre `chrome://extensions` (o `edge://extensions`).
2. Activa **Modo de desarrollador**.
3. **Cargar descomprimida** → elige esta carpeta (`extension/`).
